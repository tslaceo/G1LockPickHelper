G1LockPickHelper 1.1.2 - lockpicking helper for Gothic 1 Remake (UE4SS Lua mod)

Shows the key sequence that opens the lock in the lockpicking minigame and follows
you through it. F3 lets the mod pick the lock for you, using only moves that cannot
strain the pick.

Requires UE4SS - AngelScript Fix: https://www.nexusmods.com/gothic1remake/mods/524
Optional: Shared Mod Menu (F2) to change the settings in game:
https://www.nexusmods.com/gothic1remake/mods/194

Install: extract this archive into the game folder (the one that contains the G1R
folder), so that G1R\Binaries\Win64\ue4ss\Mods\G1LockPickHelper\ exists.
Uninstall: delete that folder.

Keys: F4 shows/hides the hint; F3 auto-picks the open lock (or the one you open within
5 seconds) and stops auto-pick. Gamepad: the hint shows the game's button icons;
press reset twice (Triangle / Y) to auto-pick the lock. Settings: settings.ini in the mod
folder, written on the first start (language: auto, en or ru).

A DualSense shows Xbox icons? Steam Input makes it look like an Xbox pad: turn Steam
Input off for the game, or choose "PlayStation 5" in the game's "Button icons" option.
After switching "Button icons" from a set back to "Auto" the game keeps the old set
until a restart. Shared Mod Menu opened right after leaving a lock loses its mouse
cursor: press F2 twice.
